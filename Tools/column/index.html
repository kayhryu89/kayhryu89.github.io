04 · Numerical run

Numerical safeguards & assumptions

Conservative upwind axial and axisymmetric radial finite volumes, explicit CFL-limited transport, implicit local LDF exchange, exact cellwise species inventory balance. First-order reference implementation, not an OCFE solver. Constant isothermal gas velocity/pressure, dilute tracer and specified dispersion; no energy, Ergun flow, or competitive species equation. Increase nz/nr and check convergence before physical interpretation.

Model validity

This is a numerically conservative 2D finite-volume reference solver. It is intended as the acceptance benchmark for later axial OCFE + radial collocation. First-order spatial/time convergence means fronts are numerically diffused on coarse grids.

Mass conservation is checked on the species inventory (gas + adsorbed phase). That alone does not validate constant-density flow, dispersion inputs, equilibrium/kinetic transferability, or the physical accuracy of breakthrough predictions.
