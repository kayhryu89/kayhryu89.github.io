03 · Estimate kLDF / axial dispersion from measured data

Estimate the LDF rate k and/or axial dispersion Dz against the measured Cout/Cin curve using 1D isothermal Global OC by default, or select FVM for comparison. Equilibrium and all other model parameters are held fixed. This first release supports adsorption step experiments only; provide the measured bed and inlet conditions, set initial gas and solid loadings to zero, and ensure the numerical time window covers the measurements.

If checked, fitting sets radial rings to 1 and radial inlet/velocity profile amplitudes to zero internally. Any 2D maldistribution is therefore excluded and parameter transfer must be verified separately. Uncheck to require already configured uniform 1D conditions.

Analyze a measured curve, then run parameter fitting.

Parameter fitting uses the independently chosen 1D Global OC (default) or original 1D FV forward model. Global OC requires at most 80 axial nodes, and returns a global limiter diagnostic. Always test parameter recovery, mesh and timestep convergence. The fitted RMSE is in-sample, not predictive accuracy. The fit includes an automatic doubled-grid check when possible. Strongly correlated kLDF and Dz may not be separately identifiable from one outlet curve. Use independent measurements for validation.

Net inlet−outlet retained gas includes any gas-phase hold-up change; it is not independently measured solid-phase capacity. Use adsorption step experiments at constant volumetric flow and nominal feed concentration for these metrics. Breakthrough thresholds use linear interpolation.

Model validity

Default for isothermal 1D/2D: global orthogonal collocation (Legendre GLL, no finite elements). The established 1D/2D FVM remains an independent conservative comparison option. Both Global OC and FVM support 2D non-isothermal LTE, while 1D Global OC fitting is isothermal. A coupled non-isothermal 2D finite-volume option adds one local thermal-equilibrium temperature field, adsorption heat, axial/radial conduction and wall exchange. The experimental 1D GLL OCFE uses a global mass-conserving limiter; unlike the FV reference, it has not established local positivity/conservation or front accuracy across operating conditions. It is intended as the acceptance benchmark for later axial OCFE + radial collocation. First-order spatial/time convergence means fronts are numerically diffused on coarse grids.

Mass conservation is checked on the species inventory (gas + adsorbed phase). That alone does not validate constant-density flow, dispersion inputs, equilibrium/kinetic transferability, or the physical accuracy of breakthrough predictions.
