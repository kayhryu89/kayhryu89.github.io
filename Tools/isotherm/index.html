03 · Fitting settings

Pointwise confidence interval of fitted mean uptake, plus optional individual coefficient intervals (conditional on the fitted model); not a prediction interval. Unweighted: residual bootstrap; with sigma: Gaussian parametric bootstrap. Computed for the selected model only after fitting, with re-fitting and fixed input x values.

Default fitting uses multistart, log-coordinate, box-constrained projected L-BFGS with a finite-difference gradient. This is not SciPy/Fortran L-BFGS-B; legacy LM is retained for comparison. Always inspect residuals and convergence.

Automatic mode compares non-duplicate eligible models using pressure-interleaved cross-validation, complexity and physical checks. It does not establish independent predictive validity.
