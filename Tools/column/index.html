04 · Numerical run

For a defensible spatial comparison, select Global OC and 1D FV-BE. Both use the SAME first-order BE transport → implicit BE LDF split and identical time samples/substeps; the distinct spatial operators and Global OC limiter remain differences. The existing 1D/2D FV production solver remains explicit transport + implicit LDF, and should NOT be compared directly on runtime. 2D Global OC uses one tensor-product polynomial domain (z, x=(r/R)²), without finite elements. Radial collocation uses nonuniform nodes and cylindrical flux weighting. Global OC does not guarantee monotone fronts; inspect limiter amplitude.

Gas and solid share one local temperature T(z,r,t). Positive adsorption heat releases energy; gas heat capacity, solid heat capacity and effective conductivities are assumed constant. This mode has prescribed superficial gas velocity and pressure; no Ergun/momentum or variable-density solution. Non-isothermal and 2D calculations use FVM; Global OC supports 2D nonisothermal LTE with coupled heat release; 1D Global OC remains isothermal for fitting.

The existing Column temperature field above is the reference temperature for q*. The van't Hoff option assumes a constant adsorption enthalpy for an effective Langmuir/Henry affinity; imported empirical isotherms receive an APPROXIMATE horizontal pressure shift, not a thermodynamically validated multitemperature model. Imported kinetic rates use the reference temperature; temperature dependence of k is optional.

Numerical safeguards & assumptions

Conservative upwind axial and axisymmetric radial finite volumes, explicit CFL-limited transport, implicit local LDF exchange, exact cellwise species inventory balance. First-order reference implementation, not an OCFE solver. Isothermal by default; optional 2D local-thermal-equilibrium energy transport, adsorption heat and wall exchange. Fixed velocity/pressure, dilute tracer and no Ergun or multicomponent species equation. Increase nz/nr and check convergence before physical interpretation.

Fit measured breakthrough with 1D Global OC or FVM

Estimate the LDF rate k and/or axial dispersion Dz against the measured Cout/Cin curve using 1D isothermal Global OC by default, or select FVM for comparison. Equilibrium and all other model parameters are held fixed. This first release supports adsorption step experiments only; set radial rings to 1, radial inlet/velocity amplitudes to zero, and initial gas/solid loadings to zero. Ensure the simulation end time covers every measurement.

If checked, fitting temporarily sets radial rings to 1 and radial inlet/velocity profile amplitudes to zero without changing the forward-simulation controls. Any 2D maldistribution is therefore excluded and parameter transfer must be verified separately. Uncheck to require already configured uniform 1D conditions.

Analyze a measured curve, then run parameter fitting.

Parameter fitting uses the independently chosen 1D Global OC (default) or original 1D FV forward model. Global OC requires at most 80 axial nodes, and returns a global limiter diagnostic. Always test parameter recovery, mesh and timestep convergence. The fitted RMSE is in-sample, not predictive accuracy. The fit includes an automatic doubled-grid check when possible. Strongly correlated kLDF and Dz may not be separately identifiable from one outlet curve. Use independent measurements for validation.

Net inlet−outlet retained gas includes any gas-phase hold-up change; it is not independently measured solid-phase capacity. Use adsorption step experiments at constant volumetric flow and nominal feed concentration for these metrics. Breakthrough thresholds use linear interpolation.

Model validity

Default for isothermal 1D/2D: global orthogonal collocation (Legendre GLL, no finite elements). The established 1D/2D FVM remains an independent conservative comparison option. Both Global OC and FVM support 2D non-isothermal LTE, while 1D Global OC fitting is isothermal. A coupled non-isothermal 2D finite-volume option adds one local thermal-equilibrium temperature field, adsorption heat, axial/radial conduction and wall exchange. The experimental 1D GLL OCFE uses a global mass-conserving limiter; unlike the FV reference, it has not established local positivity/conservation or front accuracy across operating conditions. It is intended as the acceptance benchmark for later axial OCFE + radial collocation. First-order spatial/time convergence means fronts are numerically diffused on coarse grids.

Mass conservation is checked on the species inventory (gas + adsorbed phase). That alone does not validate constant-density flow, dispersion inputs, equilibrium/kinetic transferability, or the physical accuracy of breakthrough predictions.
